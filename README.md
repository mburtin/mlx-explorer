# MLX Explorer

Browse [MonolixSuite](https://www.simulations-plus.com/software/monolix/) projects and explore their results directly in [Positron](https://positron.posit.co/).

## Features

- **Project Explorer** — Automatically discover and list **Monolix** and **Simulx** runs in your workspace, with the ability to organize them into groups.
- **Rename Runs** — Rename a run from the explorer: its project file, run folder and sidecar files move together, and every path they declare follows.
- **Results Summary** — View key results from your runs, including parameter estimates and likelihood-based criteria.
- **Model Viewer** — Preview the models used in your runs.
- **Data Explorer** — Explore and analyze run datasets using Positron's built-in Data Explorer.
- **Results Export** — Export result tables as SVG or PNG images, or copy them as R code.
- **Run Descriptions** — Add descriptions to document and organize your runs.

## Requirements

- [Positron 2026.09+](https://positron.posit.co/).
- MonolixSuite must be installed with a valid license to access all features.
